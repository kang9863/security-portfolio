# KISA 교육 수료 내역

> 이 문서는 포트폴리오에 공개 가능한 범위로 정리한 KISA아카데미 교육 수료 내역입니다. 원본 수료증에는 생년월일과 증서번호가 포함되어 있어 GitHub에는 원본 PDF를 업로드하지 않고, 과정명/기간/시간/기관만 공개합니다.

## 1. 개요

2026년 수료한 한국인터넷진흥원 교육 4개 과정의 내역입니다. 웹 취약점 분석, 버그헌팅 실습, 침입탐지/차단 시스템 실습 경험을 보완 증빙으로 정리했습니다.

## 3. 포트폴리오와 연결되는 지점

### 버그헌팅실습훈련 중급/고급

버그헌팅 실습훈련은 포트폴리오의 웹 취약점 보고서와 직접 연결됩니다.

연결 문서:

- SQL Injection 보고서
- XSS 보고서
- 로그인 로직 5종 분석
- 웹 퍼징/XSS/IDOR 복습 노트
- AI/MCP 기반 버그헌팅 워크플로우

이 교육은 단순히 취약점 이름을 외우는 것보다, 취약점 후보를 어떻게 재현하고 보고서로 정리할지에 대한 기준을 세우는 데 도움이 되었습니다.

### 정보보호제품군 실습훈련

침입탐지 및 차단 시스템 교육은 포트폴리오의 Nessus/IDS 보고서와 연결됩니다.

연결 문서:

- Nessus / IDS 실습 결과 정리
- 웹 공격 탐지 룰 작성 흐름
- Snort / Suricata 룰 기반 탐지 정리

공격 관점에서 취약점을 찾는 것뿐 아니라, 방어 관점에서 어떤 트래픽이 탐지되어야 하는지 생각하는 계기가 되었습니다.

## 4. 공개 기준

원본 수료증에는 다음 정보가 포함되어 있어 공개 저장소에는 올리지 않습니다.

- 생년월일
- 증서번호
- 원본 PDF 파일

공개 포트폴리오에는 교육과정명, 교육기간, 교육시간, 교육장소만 남깁니다. 필요 시 원본 수료증은 별도 제출 또는 면접 과정에서만 제시하는 방식이 안전하다고 판단했습니다.

## 5. 정리

이 수료 내역은 포트폴리오의 실습 보고서가 단순 개인 정리에서 끝나는 것이 아니라, KISA아카데미의 버그헌팅/보안 제품 실습 흐름과 연결되어 있다는 점을 보여주는 보조 증빙입니다.

앞으로 포트폴리오에서는 수료증 자체보다 교육에서 배운 내용을 실제 보고서 품질, 재현 절차, 대응 방안 정리로 연결하는 데 집중할 계획입니다.
