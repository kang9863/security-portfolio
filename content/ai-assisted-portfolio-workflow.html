AI를 활용한 자료 통합과 포트폴리오 제작

흩어진 보안 학습 자료를 AI와 함께 검토하고, 근거 데이터·분석 문서·GitHub Pages 포트폴리오로 연결한 작업이다. 2026년 10월에 진행한 자료 정리와 문서·웹 제작 흐름을 기록한다. AI가 만든 초안과 실제 자료로 확인한 사실을 구분하는 방식으로 작업했다.

1. 자료 통합

기존 공개 포트폴리오, Notion, Obsidian과 로컬 포트폴리오 폴더를 확인했다. 같은 자료의 복사본은 별도 프로젝트 실적으로 집계하지 않고, 문서와 캡처·코드·로그의 관계를 정리했다. 특정 Notion pentest 페이지와 그 하위 내용은 사용자가 제외한 범위를 유지했다.

2. 분석 결과 표현을 검토한 사례

초안에서 혼동할 수 있는 내용 근거에 맞춰 정리한 표현
MCP 연결과 취약점 실행 연결 확인과 별도 CLI 검증을 구분
로그인 패턴 5개 구현 비교 대상 수; 취약점 발견 5건과 구분
캡처 파일 이름 실제 화면과 대조해 크래시·실행 증거 여부 확인
문서의 과거 테스트 수 해당 시점 기록; 현재 재실행 성공 수와 구분
AI 구조도 설계 경험; 운영·비용 절감 성과와 구분

3. 문서와 웹 산출물

원본 자료에서 확인한 역할·기간·결과를 근거 데이터와 상세 분석 문서에 연결했다. 공개 사이트에는 학습 자료를 본문·표·코드·캡처로 구성하고, 실제 문서 내용과 표시 결과의 일치를 확인했다.

자료 검토 → 근거 데이터 정리
  → 확인된 역할·기간·결과로 문장 작성
  → 본문·표·코드·캡처와 화면 대조
  → GitHub Pages에 공개 자료 연결
  → 모바일·검색·문서 링크 확인

4. AI와 사용자의 역할

사용자는 자료·지원 방향·연락처를 제공하고 내용과 사이트 구성을 수정했다. AI는 자료 검토·초안·코드 생성과 검증 작업을 보조했다. 이 사이트와 생성 코드를 독립적인 단독 개발 실적으로 표현하지 않고 AI를 활용한 자료 정리·제작 경험으로 설명한다.

5. 공개 결과의 확인

문서의 역할·실습 범위와 날짜를 유지하고, 원본 수료증의 개인 식별 정보나 비공개 인증 값을 공개하지 않았다. 파일과 화면을 대조하고, 목차·검색·분류와 다운로드가 실제로 이어지는지를 확인하는 작업까지 포트폴리오 제작에 포함했다.
