정찰 및 AD 공격 경로 정리

1. 개요

이 문서는 Nmap 전체 포트 스캔에서 시작해 내부망/Active Directory 환경의 공격 표면을 분류하고, 계정 확보와 권한 경로 분석으로 이어지는 학습 흐름을 정리한 것입니다.

실제 계정명, 도메인명, IP, 인증서, 해시, 키는 공개하지 않고 익명화합니다.

2. 분석 방법론

전체 포트 스캔
-> 서비스 식별
-> 웹/SMB/LDAP/Kerberos 분류
-> 계정 및 도메인 정보 수집
-> BloodHound 기반 권한 경로 분석
-> Kerberoasting 가능성 확인
-> Password Spraying 가능성 검토
-> SMB Share 탐색
-> 인증서/PFX 취급 가능성 검토
-> gMSA/권한 위임 경로 분석
-> 관리자 권한 획득 시나리오 정리

3. 정찰

Nmap은 침투테스트의 시작점으로 사용했습니다.

확인 항목:

  • 열려 있는 포트
  • 서비스 이름
  • 서비스 버전
  • 웹 서버 여부
  • SMB 노출 여부
  • LDAP/Kerberos 도메인 서비스 여부
  • WinRM/PSWA 같은 원격 관리 서비스 여부

예시 명령:

nmap -p- -T4 <target>
nmap -sC -sV -oA nmap/result <target>

4. 서비스 분류

스캔 결과는 다음 기준으로 분류합니다.

서비스 분석 목표
HTTP/HTTPS 로그인, 파일 업로드, API, 정보 노출
SMB 공유 폴더, 익명 접근, 파일 내 계정 정보
LDAP 도메인 사용자, 그룹, 정책 정보
Kerberos Kerberoasting, AS-REP Roasting 가능성
WinRM/PSWA 원격 명령 실행 가능성
MSSQL DB 인증, 권한, xp_cmdshell 가능성

5. 우선순위 판단 기준

정찰 결과가 많을수록 바로 공격으로 넘어가기보다 우선순위를 정해야 합니다. 제가 AD 풀이를 복기하면서 잡은 기준은 다음과 같습니다.

우선순위 조건 이유
1 인증 없이 읽을 수 있는 SMB/LDAP 정보 계정명, 그룹, 파일 내부 비밀번호가 나올 수 있음
2 Kerberos 관련 계정 노출 AS-REP Roasting, Kerberoasting으로 이어질 수 있음
3 웹 로그인/PSWA/WinRM 확보한 계정의 실제 접근 가능성을 검증할 수 있음
4 인증서/PFX/gMSA 파일 AD에서 권한 상승 경로로 연결될 수 있음
5 BloodHound 경로 단순 계정 탈취가 아니라 권한 관계를 설명할 수 있음

이 기준을 두면 스캔 결과가 단순 포트 목록으로 남지 않고, “어떤 서비스가 다음 단계의 단서가 되는지”를 보고서에 설명할 수 있습니다.

6. AD 공격 경로 분석

AD 환경에서는 단일 취약점보다 권한 관계가 중요합니다.

분석 질문:

  • 현재 계정이 어떤 그룹에 속하는가?
  • 어떤 공유 폴더를 읽을 수 있는가?
  • 서비스 계정 해시를 얻을 수 있는가?
  • 패스워드 스프레이가 가능한 정책인가?
  • BloodHound에서 권한 상승 경로가 보이는가?
  • 인증서나 gMSA 권한이 잘못 위임되어 있는가?

7. 대표 공격 경로 템플릿

실제 풀이에서 자주 보이는 경로는 다음처럼 정리할 수 있습니다.

익명 LDAP 또는 SMB 열람
-> 사용자명/그룹/파일 정보 수집
-> AS-REP Roasting 또는 Kerberoasting
-> 해시 크랙 또는 계정 재사용 확인
-> BloodHound로 권한 관계 확인
-> WriteDACL / GenericAll / gMSA / 인증서 경로 검토
-> WinRM/PSWA/SMB를 통해 권한 확인

보고서에서는 이 흐름을 그대로 공격 단계처럼 나열하기보다, 각 단계에서 얻은 증거를 표로 남기는 편이 좋습니다.

단계 남길 증거
정찰 포트/서비스/도메인명
계정 후보 사용자명 출처, 파일 경로, LDAP 쿼리 근거
해시/티켓 어떤 계정이 어떤 조건 때문에 roast 가능한지
권한 관계 BloodHound path, ACE, group membership
원격 접속 WinRM/PSWA/SMB 접근 가능 여부
영향도 어떤 시스템 또는 데이터까지 접근 가능한지

8. 위험도와 영향

가능한 영향:

  • 일반 계정 탈취
  • 내부 파일 공유 접근
  • 서비스 계정 해시 크랙
  • 도메인 권한 경로 노출
  • 관리자 권한 획득
  • 중요 시스템 접근

9. 보고서 작성 기준

실제 보고서 작성 시 다음을 분명히 구분합니다.

  • 발견한 서비스
  • 인증 없이 접근 가능한 정보
  • 인증 후 접근 가능한 정보
  • 권한 상승에 필요한 조건
  • 재현 절차
  • 비즈니스 영향
  • 대응 방안

10. 대응 체크리스트

  • 불필요한 포트와 서비스 차단
  • SMB 공유 권한 최소화
  • LDAP 익명 조회 제한
  • Kerberos 서비스 계정 비밀번호 강도 강화
  • 계정 잠금 정책과 MFA 적용
  • BloodHound 기준 과도한 권한 관계 제거
  • 인증서 템플릿과 gMSA 권한 위임 점검
  • 로그 모니터링과 탐지 룰 적용

11. 학습한 점

AD 침투는 도구 하나로 끝나는 문제가 아니라, 정찰 결과를 권한 관계와 연결하는 과정입니다. Nmap 결과를 단순 포트 목록으로 끝내지 않고, 각 서비스가 다음 단계의 어떤 공격 경로로 이어지는지 설명할 수 있어야 합니다.
