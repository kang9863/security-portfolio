OWASP Juice Shop 팀 프로젝트와 AI 도구 활용

교육 팀 프로젝트에서 취약점 공동 담당과 AI 담당 역할을 맡았다. HTTP 요청·응답, 별도 Kali CLI 기록과 MCP 연결 상태를 대조해 취약점 후보와 확인 결과를 구분했다. 대표 실행 기록은 2026년 6월 29일이며, 전체 프로젝트 시작·종료 기간은 별도로 확정하지 않았다.

1. 맡은 역할과 대상

항목 기록
대상 로컬 OWASP Juice Shop 실습 랩
팀 역할 취약점 공동 담당·AI 담당
핵심 작업 MCP 연결 확인, 별도 CLI·HTTP 증적 대조, 분석 보고서 정리
도구 Kali Linux, Burp Suite, sqlmap, MCP, HexStrike

2. 연결 점검과 취약점 검증의 구분

MCP의 tools/list 응답, 허용 범위와 HexStrike 상태를 먼저 확인했다. 해당 연결 점검 시점에는 Juice Shop이 내려가 있어 그 호출로 능동 테스트를 완료하지 않았다. 로그인 SQLi는 별도 Kali CLI·sqlmap 실행 기록과 HTTP 응답으로 확인한 내용이다.

MCP 도구 목록·범위·서버 상태 확인
  → 대상 앱 상태 확인
  → 해당 호출의 실제 수행 여부 기록

별도 CLI·HTTP 기록
  → 로그인 입력과 응답 대조
  → SQLi 재현 조건 정리
  → 영향·대응방안 작성

3. 로그인 SQLi 분석

로그인 요청의 입력 위치, 정상 인증 실패와 변조 요청의 응답 차이를 살펴봤다. sqlmap 기록에는 JSON email 입력의 SQLite boolean-based blind 분석이 남아 있다. 도구가 표시한 내용을 요청 구조와 응답에 연결하는 방식으로 보고서를 구성했다.

판단 단계 사용할 자료
입력 위치 로그인 요청의 JSON 필드·HTTP method
응답 변화 정상 요청과 변조 요청의 상태·본문 차이
보조 확인 별도 sqlmap CLI 출력
보고서 결론 재현 조건, 영향을 받는 인증 경계, 대응방안

4. AI 활용 방식

AI를 후보 분류와 보고서 정리에 활용하되 후보·관찰·확인 결과를 같은 상태로 합치지 않았다. 도구 목록에 존재하는 기능, 연결에 성공한 기능, 실제 대상에 실행한 기능을 나눠 기록했다. 이 구분은 전체 공격이 자동으로 끝났다는 과장된 결론을 줄이는 데 필요했다.

5. 산출물과 분석 범위

  • 팀 역할표와 공동 점검·AI 담당 기록
  • 로컬 범위, 도구 목록과 서버 연결 확인 기록
  • 로그인 SQLi의 별도 Kali CLI·sqlmap 기록과 HTTP 응답
  • 재현 조건·영향·대응방안으로 정리한 보고서

JWT·세션 값은 공개 본문에서 제외했다. MCP 연결 확인과 별도 CLI 검증을 하나의 자동 공격 실행으로 표현하지 않는다. 본인이 직접 개발한 코드 범위와 팀 인원은 별도 확인 대상이다.

6. 대응 관점과 연결 문서

SQL 쿼리와 사용자 입력은 파라미터 바인딩으로 분리하고, 오류 노출과 인증 결과 처리도 함께 점검한다. 수정 뒤에는 정상 요청과 변조 요청을 함께 비교해야 한다.

  • SQL Injection 분석
  • 인증·로그인 로직 5종
  • AI 도구의 실행 상태와 증거 관리
